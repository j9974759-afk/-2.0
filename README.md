# JinJin Portfolio

本地预览版本，使用 HTML / CSS / 原生 JavaScript，无依赖安装。

## 打开方式

推荐：在此文件夹打开终端，运行 `npm run dev`，浏览器访问 http://127.0.0.1:4173。

也可以双击 `dist/index.html` 离线预览；微信复制功能建议使用本地服务器，文件模式下浏览器可能限制剪贴板。

## 修改位置

- 页面内容：`dist/index.html`
- 颜色、排版、响应式：`dist/styles.css`
- 项目详情和播放内容：`dist/app.js`
- 图片及视频：`dist/assets`
- 设计与内容说明：`设计规范与内容结构.md`

`npm run check` 检查页面脚本语法。

本地服务器固定使用 4173 端口，支持视频分段请求与拖动进度。按 Ctrl+C 停止服务。没有构建步骤，没有后端服务和表单提交。联系按钮打开用户的邮件或电话应用，不会自动发送任何信息。
